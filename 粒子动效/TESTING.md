# 粒子星球 · 本地测试指南

## 启动方式

服务器已在后台运行，访问地址：

```
http://127.0.0.1:8000/index.html
```

如需重启服务器（在项目目录下执行）：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

## 首次使用流程

1. 浏览器打开 `http://127.0.0.1:8000/index.html`
2. 点击页面中央的 **"启程"** 按钮
3. 允许摄像头权限（必须，MediaPipe 摄像头访问需要 localhost 安全上下文）
4. 戴上耳机体验 BGM 和音效空间感

## 调试面板

页面顶部中央有 **DEBUG PANEL**，实时显示：

| 字段 | 含义 |
|------|------|
| FPS | 渲染帧率（绿色≥50/黄色≥30/红色<30）|
| 检测手数 | MediaPipe 识别到的手数量 |
| 手1 / 手势 | 第一只手的左右标签 + 识别到的单手手势 |
| 手2 / 手势 | 第二只手（双手时显示）|
| 手1 手指[T I M R P] | 拇指/食指/中指/无名指/小指 伸展状态(1伸/0屈) |
| 当前手势 | 最终生效的手势（含双手组合）|
| 能量 | 捏合充能进度 0~100% |
| 音频 | BGM 播放状态 |
| 相机距离 | 相机到星球中心的距离 |
| 事件日志 | 最近 8 次触发的手势/快捷键事件 |

**按 `D` 键** 可隐藏/显示调试面板。

## 音效快速验证（无需手势）

点击"启程"启动音频后，直接按数字键试听对应音效 + 触发视觉特效：

| 按键 | 音效 | 视觉效果 |
|------|------|----------|
| `1` | 握拳低频下扫 | 相机远离 |
| `2` | 张开 whoosh | 相机靠近 |
| `3` | 流星叮咚 | 召唤流星雨 |
| `4` | 曲速上扫 | 相机前冲 + Bloom 暴增 + 颜色偏移 |
| `5` | 捏合短音 | 能量满格 |
| `6` | 超新星爆炸 | 2000 粒子向外炸开 + 相机抖动 |
| `7` | 黑洞下扫 | 粒子向内坍缩 |
| `8` | 宇宙膨胀琶音 | 星环向外推 |
| `9` | (无音效) | 仅触发超新星视觉 |
| `0` | (无音效) | 仅召唤一颗流星 |

> 这些快捷键也会出现在调试面板的"事件日志"里，方便确认触发。

## 常见问题排查

### 摄像头打不开 / 黑屏
- 确认地址是 `http://127.0.0.1:8000` 或 `http://localhost:8000`（不能直接双击打开 html，file:// 协议无法访问摄像头）
- 浏览器地址栏左侧检查摄像头权限是否被拒绝，需允许
- 关闭其他占用摄像头的程序（Zoom/Teams/微信等）

### 没有声音
- 必须先点击"启程"按钮（浏览器自动播放策略要求用户手势）
- 检查调试面板"音频"字段是否显示"BGM 播放中"
- 点击右上角 🔊 按钮确认未静音
- 检查系统音量和浏览器标签页是否被静音

### 手势识别不灵敏
- 保持手部在摄像头中央，距离适中（手臂完全入镜）
- 光线充足，避免逆光
- 调试面板"手1 手指"字段可看到实时手指状态，据此调整手势
- 捏合手势需拇指尖与食指尖距离小于手掌长度的 40%

### FPS 偏低（红色）
- 关闭其他浏览器标签
- 降低浏览器窗口分辨率
- 按 `D` 隐藏调试面板（减少 DOM 更新）
- 若仍卡顿，可减小 CONFIG.particleCount

### 双手不识别
- 确认 `maxNumHands: 2` 已生效（调试面板"检测手数"应为 2）
- 两只手都要完整入镜，不要互相遮挡
- 双手手势需两只手同时满足条件（如超新星需两只手都张开且靠近）

## 停止服务器

服务器在后台运行。如需停止，关闭终端或在任务管理器结束 python 进程即可。
