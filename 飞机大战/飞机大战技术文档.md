# 飞机大战 — 网页游戏技术文档（v2.0）

> 版本：v2.0  
> 目标：基于原生 HTML/CSS/JS，构建科技风格、多飞机解锁、10 关卡制、含 Boss 战的飞机大战网页游戏。

---

## 一、项目概述

### 1.1 项目目标
开发一款在浏览器中直接运行的飞机大战游戏，零外部依赖。玩家操控战机，通过 10 个关卡，挑战 Boss，收集装备，逐步解锁战机，最终解锁隐藏神器"绒绒小天才"。

### 1.2 技术栈
| 层面 | 技术 | 说明 |
|------|------|------|
| 渲染 | Canvas 2D | 全游戏画面基于 `<canvas>` 绘制 |
| 样式 | CSS3 | 科技风 UI 界面 |
| 逻辑 | 原生 JavaScript (ES6+) | 面向对象组织 |
| 构建 | 无 | 纯前端，单 html 文件，零依赖 |
| 资源 | 本地照片裁剪 + 代码绘制 | 飞机素材来源于本地照片裁剪 |

## 二、飞机系统

### 2.1 飞机解锁流程

```
初始只有 钢铁凶兽
    ↓ 通关第 3 关
解锁 银色流星
    ↓ 通关第 6 关
解锁 赛道魔术
    ↓ 三架全部解锁
解锁隐藏飞机 ★ 绒绒小天才 ★
```

### 2.2 飞机详细设计

| 飞机名称 | 解锁条件 | 特点 | 射击方式 | 专属技能 | 属性倾向 |
|----------|----------|------|----------|----------|----------|
| **钢铁凶兽** | 初始解锁 | 厚重装甲，火力凶猛 | 双发直线弹 | 铁壁冲锋（短暂无敌+加速） | 攻击力 ★★★★ 速度 ★★ 生命 ★★★ |
| **银色流星** | 通关第 3 关 | 极速灵动，轻盈飘逸 | 散射弹幕 | 流星突袭（瞬间位移+全屏弹幕） | 攻击力 ★★★ 速度 ★★★★ 生命 ★★ |
| **赛道魔术** | 通关第 6 关 | 花式技巧，弹幕花哨 | 弧形弹道 + 追踪弹 | 魔术幻影（制造分身迷惑敌人） | 攻击力 ★★★ 速度 ★★★ 生命 ★★★ |
| **绒绒小天才 ★** | 三架全解锁 | 终极隐藏战机 | 普通射击 | **一键清屏**（全屏秒杀所有敌机+Boss 扣 30% HP） | 攻击力 ★★★★★ 速度 ★★★★★ 生命 ★★★★★ |

### 2.3 飞机素材来源

飞机外观从以下本地照片裁剪提取：

| 文件 | 对应飞机 | 处理方式 |
|------|----------|----------|
| `钢铁凶兽.png` | 钢铁凶兽 | 从照片中抠出飞机主体，转为 Canvas 可绘制的图像/透明 PNG |
| `银色流星.png` | 银色流星 | 同上 |
| `赛道魔术.png` | 赛道魔术 | 同上 |
| `绒绒小天才.png` | 绒绒小天才 | 保留绒绒风格，做发光特效处理 |

**Builder 处理说明：**
- 将每张照片中的飞机主体裁剪为透明背景 PNG
- 缩放至适合游戏的大小（约 48×48 ~ 64×64 像素）
- 使用 `Image` 对象加载到 Canvas 中绘制
- 如果照片背景复杂，需手动抠图 + 边缘羽化
- 每架飞机需附带引擎发光特效（代码绘制尾焰粒子）

──────────┼────────────────────────────────────

第 8 关 │ 生存关 - 大量自爆机追踪
──────────┼────────────────────────────────────
第 9 关 │ ★ 小 Boss 关 - 随机 Boss 登场

| 5 | 20 | 大型+自爆 | 无 | 中级 | 300 金币 |

```

  → 如果当前关有 Boss → Boss 战
  → 通关 → 装备选择/升级界面 → 下一关
```

## 四、Boss 系统

### 4.1 Boss 池（四个随机 Boss）

四个 Boss 在每次游戏开始时随机分配，3、6、9 关的小 Boss 和 10 关的终极 Boss 从池中抽取。

#### Boss 形象设计

| Boss 名称 | 网络梗来源 | 外形特征 | Boss 弹幕风格 |
|-----------|-----------|----------|--------------|
| **蔡徐坤** | 偶像练习生 / 篮球梗 | 背带裤 + 中分头 + 篮球 | 篮球弹幕（弹跳追踪）+ 鸡你太美音符弹幕 |
| **东北雨姐** | 东北农村大姐大 | 大红袄 + 大碴子口音 | 铁锅炖弹幕 + 大葱横扫 + 酸菜缸召唤 |
| **嘉豪** | "隔壁班嘉豪" 校园梗 | 黑卫衣 + 黑口罩 + 耳机 | 魔性舞蹈弹幕 + That Girl 音波攻击 |
| **C罗** | 葡萄牙足球巨星 | 足球服 CR7 + 帅气发型 | 足球射门弹幕 + SIU 庆祝冲击波 |

#### 小 Boss vs 终极 Boss 参数

| 属性 | 小 Boss（3/6/9 关） | 终极 Boss（第 10 关） |
|------|---------------------|----------------------|
| HP | 50~80 | 200 |
| 阶段数 | 1 | 3 |
| 攻击模式 | 2 种 | 4 种（逐阶段解锁） |
| 弹幕密度 | 中 | 极高 |
| 移动方式 | 固定水平移动 | 全屏移动 + 瞬移 |
| 掉落 | 1 个装备升级材料 | 3 个装备升级材料 + 大量金币 |

### 4.2 Boss 攻击模式

#### 蔡徐坤
- **阶段 1**：投掷篮球（弹道抛物线，落地反弹）
- **阶段 2**（终极 Boss 专属）："鸡你太美" — 音符从屏幕两侧飞出
- **阶段 3**（终极 Boss 专属）：铁山靠 — 快速冲锋撞击

#### 东北雨姐
- **阶段 1**：大葱横扫（横向长条弹幕）
- **阶段 2**（终极 Boss 专属）：撒酸菜（全屏随机落点）
- **阶段 3**（终极 Boss 专属）：铁锅炖大鹅（召唤大铁锅罩顶，需在缝隙中躲避）

#### 嘉豪
- **阶段 1**：魔性舞蹈（不规则弹幕轨迹）
- **阶段 2**（终极 Boss 专属）：That Girl 音波（环形扩散音波）
- **阶段 3**（终极 Boss 专属）：嘉豪魔性分身（召唤 2 个分身同时攻击）

#### C罗
- **阶段 1**：射门（直线高速足球弹幕）
- **阶段 2**（终极 Boss 专属）：倒挂金钩（弧形弹幕 + 追踪）
- **阶段 3**（终极 Boss 专属）：SIU——！（全屏冲击波，需在屏幕边缘躲避）

### 4.3 Boss 随机分配机制

```javascript
// 每次新游戏开始时，从 4 个 Boss 中随机抽取排序
// 第 3 关 ← 抽第 1 个
// 第 6 关 ← 抽第 2 个
// 第 9 关 ← 抽第 3 个
// 第 10 关 ← 抽第 4 个（终极强化版，HP×3，弹幕密度×2）

// 确保每局游戏 4 个 Boss 不重复，且每个 Boss 只出现一次
```

## 五、装备系统

### 5.1 装备分类

每关通关后，玩家可以选择 **一件装备** 或 **升级已有装备**。

三大装备类型，每种 3 个等级：

#### 🔥 灼烧系 — 持续伤害

| 装备名称 | 等级 | 效果 |
|----------|------|------|
| **烈焰之羽** | Lv.1 | 子弹命中后附加灼烧效果，每秒造成 5 点伤害，持续 2 秒 |
| **焚天炎刃** | Lv.2 | 灼烧伤害提升至每秒 12 点，持续 3 秒，附带灼烧扩散效果 |
| **业火红莲** | Lv.3 | 灼烧伤害提升至每秒 25 点，持续 4 秒，灼烧期间目标受到的伤害 +20% |

#### 🛡️ 护盾系 — 生存防御

| 装备名称 | 等级 | 效果 |
|----------|------|------|
| **铁壁之铠** | Lv.1 | 获得 1 层护盾，可抵挡 1 次伤害 |
| **虚空壁垒** | Lv.2 | 获得 2 层护盾，护盾状态下伤害 +10% |
| **不灭金身** | Lv.3 | 获得 3 层护盾，护盾状态下伤害 +20%，护盾破碎时清屏弹幕 |

#### ❄️ 减速系 — 控制辅助

| 装备名称 | 等级 | 效果 |
|----------|------|------|
| **冰霜之息** | Lv.1 | 子弹命中后减速敌人 20%，持续 2 秒 |
| **寒冰领域** | Lv.2 | 子弹命中后减速敌人 35%，持续 3 秒，范围冻结效果 |
| **时空凝滞** | Lv.3 | 子弹命中后减速敌人 50%，持续 4 秒，有概率将敌人定身 1 秒 |

### 5.2 装备选择/升级规则

- 每 **通关一关**，进入装备选择界面
- 从三个类别中各随机展示 **1 件可供选择**的装备
- 如果该装备已拥有，则选择后 **升级一级**
- 如果某类别已升满（Lv.3），则不再出现该类别
- 装备效果在整局游戏中 **持续生效**，不会重置
- 完美策略：先升满一个系，再升另一个

## 十二、照片处理指南

### 12.1 飞机抠图

由于三架飞机 + 隐藏飞机使用本地照片，需要以下处理：

**处理步骤：**
1. 将 `钢铁凶兽.png`、`银色流星.png`、`赛道魔术.png`、`绒绒小天才.png` 四张照片中的飞机主体裁剪出来
2. 去除背景，保留透明 PNG
3. 缩放至 48×48 ~ 64×64 像素的精灵尺寸
4. 另存为 `img_steel.png`、`img_silver.png`、`img_track.png`、`img_rongrong.png`

**代码加载方式：**
```javascript
const planeImages = {
  'steel': new Image(),
  'silver': new Image(),
  'track': new Image(),
  'rongrong': new Image()
};
planeImages['steel'].src = 'img_steel.png';
// ... 类似方式加载
```

**如果无法直接抠图**，可使用以下方案：
- 在 Canvas 中绘制时，使用 `drawImage` 裁剪原始照片的指定区域
- 定义每张照片的裁剪坐标：`{ sx, sy, sw, sh }`
